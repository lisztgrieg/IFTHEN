First-Time Setup

Enter a client name, name the event, optionally attach tags, an outcome, and a video link, then tap the first skill button to auto-start scoring.

Use Export Backup before deleting browser data or switching devices.

Privacy

This MVP stores scoring data locally in this browser. It does not send event data to a central server unless you later add that feature.

Install On iPhone

Open the hosted app in Safari, tap Share, then choose Add to Home Screen. Updates appear after you publish new files and the app detects a new service worker version.

How this works is you'll fill in some blanks to name the event before you start it. You can watch a video, read a transcript, or use this as an onlooker of a confrontation or discussion really of any kind. Each clause in the conversation, or event as we call it, gets an intensity score. You tap the corresponding button between 0 and 10 as the clause is spoken. The app records the order and timing of each button. When you're done you can look through the various formats of data visualization and see what you learn. Feedback is welcome.
