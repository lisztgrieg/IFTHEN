Backup & Restore

First-Time Setup

Enter a client name, name the event, optionally attach tags, an outcome, and a video link, then tap the first skill button to auto-start scoring.

Use Export Backup before deleting browser data or switching devices.

Privacy

This MVP stores scoring data locally in this browser. It does not send event data to a central server unless you later add that feature.

Install On iPhone

Open the hosted app in Safari, tap Share, then choose Add to Home Screen. Updates appear after you publish new files and the app detects a new service worker version.
